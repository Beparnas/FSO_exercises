# FSO_exercises
monorepo for the exercises made while completing the University of Helsinki's [FullStackOpen course](https://fullstackopen.com/en/). Weee look at me, doing web development!

# structure
Each part of the course is organized into Projects. Since the sections of the course frequently re-use project materials, I've decided to not duplicate the folders, and instead create a separate src directory for each part of the course, so that `main` still displays all of my work. 

Summary markdown files are stored in each Project directory, I use this to keep track of whether I've completed all of the exercises. subdirectories beyond this vary depending on the project.
